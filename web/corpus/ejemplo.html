Página de ejemplo del repositorio

Servida desde este mismo sitio y renderizada por el motor Nuby dentro de tu navegador

HTML de verdad

El motor parsea este documento con su propio tokenizador y construye el árbol del DOM.

CSS de verdad

Flexbox, degradados, bordes redondeados, tamaños de fuente y tablas se calculan aquí dentro.

Píxeles de verdad

El resultado se rasteriza en el framebuffer del motor y se envía a este canvas.

Degradado lineal: pintado por el rasterizador del motor, no por CSS del navegador.
EtapaQué hace

CSSCascada y valores computados
LayoutBloques, flujo en línea, flexbox, tablas
