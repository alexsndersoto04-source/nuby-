Nuby — el motor de navegador ejecutándose dentro de tu navegador

Lo que ves abajo son píxeles producidos por el motor Nuby escrito en C++, compilado a WebAssembly y ejecutándose en tu equipo: el parser HTML, el motor CSS, el layout, el rasterizador, las fuentes TrueType y el buscador BM25 son los mismos del repositorio. No hay servidor: nadie está mandando imágenes desde una máquina remota. Haz clic, escribe en la caja de búsqueda, usa la rueda.

Iniciando el motor…

Qué es real en esta página

  • El motor C++ completo compilado a WebAssembly (web/nuby.wasm).
  • La interfaz del navegador la pinta el motor con su propio rasterizador.
  • El buscador es BM25 sobre 995 documentos del rastreo real (nuby_engine/data/crawl_pages.tsv).
  • Las fuentes son los mismos ficheros TrueType que usa la versión nativa.

Qué no puede hacer aquí (y por qué)

  • No ejecuta JavaScript de las páginas: C++ para WebAssembly no tiene excepciones en esta cadena de herramientas. La versión nativa sí lo ejecuta.
  • No navega a webs externas: el navegador solo deja leer respuestas del mismo origen (CORS). Si intentas abrir otra web, verás el error real del navegador.
  • No escribe en disco: el navegador no lo permite.
  • La versión nativa (nuby_engine) sí hace todo eso y tiene 20/20 pruebas.

Navegación (se ejecuta dentro del motor)

El motor resuelve, descarga y pinta estas URLs igual que en la versión nativa. La página de ejemplo vive en este mismo sitio para que el navegador permita leerla (mismo origen).
