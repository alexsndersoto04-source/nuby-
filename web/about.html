Qué es real en Nuby y qué no

Esta página existe para que nadie tenga que adivinar qué hace el proyecto.

Real, verificado con pruebas

  • Parser HTML propio (tokenizador, árbol de nodos, atributos).
  • Motor CSS propio (selectores, cascada, valores computados, flexbox, degradados, sombras).
  • Layout propio (bloques, flujo en línea, tablas, flexbox) y rasterizador con antialiasing.
  • Fuentes TrueType reales leídas y trazadas por el motor (nuby_engine/data/fonts).
  • Buscador BM25 real sobre un rastreo real de miles de páginas (nuby_engine/data/crawl_pages.tsv, actualizado por GitHub Actions en cada rastreo).
  • La interfaz del navegador (pestañas, barra de direcciones, resultados, historial, configuración) la pinta el motor; no hay HTML de interfaz en el servidor.
  • 22/22 suites de pruebas en la versión nativa (cd nuby_engine && make test).

Real en la versión nativa

  • Descarga sitios por HTTP y HTTPS y los pinta (la red la hace el propio motor).
  • Ejecuta JavaScript de las páginas con su intérprete propio (lexer → AST → evaluador).
  • Formularios reales: campos, foco, teclado, envío implícito.

Limitaciones de la versión de navegador (WebAssembly)

  • No ejecuta JavaScript de las páginas: C++ para WebAssembly no tiene excepciones en la cadena de herramientas usada. El motor lo declara en lugar de fingirlo.
  • Solo puede leer del mismo origen (política CORS del navegador); abrir webs externas falla con el error real del navegador.
  • No escribe en disco: no guarda historial ni descargas entre visitas.

Limitaciones generales

  • No es un navegador compatible con la web completa: no implementa todo el CSS ni todo el DOM de los estándares, y muchas páginas reales se verán imperfectas o fallarán.
  • No hay despliegue público permanente de la versión nativa; esta página y el motor en wasm son lo que se publica de forma automática.
