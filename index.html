Nuby

Motor de navegador escrito desde cero en C++20 (HTML, CSS, layout, rasterizado, fuentes TrueType, JavaScript e índice de búsqueda BM25). Todo lo que muestra lo calcula el propio motor: no usa WebKit, ni Chromium, ni ningún motor ajeno.

Abrir el motor ejecutándose en el navegador →

Qué hay en marcha ahora

  • Build de navegador (WebAssembly): el motor completo compilado a wasm se ejecuta dentro de la página web/index.html. No necesita servidor.
  • Build nativa: el servidor C++ entrega al visitante los píxeles que pinta el motor y recibe sus clics y teclas. Tiene 20/20 pruebas automáticas.

Ejecutar la versión nativa

cd nuby_engine
make            # compila el motor
make test       # 20 suites de pruebas
./bin/nuby_engine --port 8080

Después abre http://localhost:8080.

Compilar la versión de navegador

bash nuby_engine/wasm/build_wasm.sh   # necesita zig (pip install ziglang)
python3 -m http.server 8099 --directory web
# abre http://localhost:8099
